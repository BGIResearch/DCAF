### Installation
```bash
git clone https://github.com/BGIResearch/DCAF.git

cd DCAF

pip install .

pip install -r requirements.txt
```

### Demo for DCAF-data
```bash
python run_recover.py
```

### Demo for DCAF-criterion
```bash
python run_measure.py
```
